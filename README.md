# Open Sales Engineering

A dependency-free static website for [Open Sales Engineering](https://github.com/open-sales-engineering),
featuring [Open Field Engineer](https://github.com/open-sales-engineering/open-field-engineer).

Open [`index.html`](index.html) directly in a browser. No JavaScript, install, or
build step is needed.

GitHub Pages publishing uses the [Deploy static site workflow](.github/workflows/pages.yml).
